# Mutual Fund Analysis Dashboard

## 📌 Project Overview

This project analyzes mutual fund data using Python and Power BI.

The project focuses on data cleaning, analysis, ranking, and visualization to identify and compare mutual fund performance.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Power BI
- CSV

## 📊 Project Features

- Data cleaning and preprocessing
- Mutual fund data analysis using Python
- Fund ranking and scoring
- Top mutual fund identification
- Interactive Power BI dashboard
- Data visualization and insights

## 📁 Project Files

- `Mutual Fund Analysis.ipynb` – Python data analysis
- `Mutual Fund Dashboard.pbix` – Power BI dashboard
- `Mutual_Funds.csv` – Dataset

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Mutual Fund Analysis.ipynb` in Jupyter Notebook.
3. Make sure `Mutual_Funds.csv` is in the same folder.
4. Run the notebook cells.
5. Open `Mutual Fund Dashboard.pbix` using Power BI Desktop.

## 🎯 Objective

The objective of this project is to analyze mutual fund data and present useful insights through Python-based analysis and an interactive Power BI dashboard.
